# Water column demo

Static build of a prototype viewer: 83 Argo profiles (NW Atlantic, June 2023, public data via Ifremer ERDDAP) drawn as a 3D field whose colour is the measured variable and whose opacity is how much measurement stands behind each point. Sea floor from GEBCO_2021.

Every file here is written by a CI workflow in a private source repository on each change; nothing is edited in this repository by hand. Served at https://tomascorreag.github.io/water-column-demo/ (console) and `/showcase.html` (walkthrough).
